Guide for adding a format

A format tells Croco Analyst where the transactions are in your bank's statement. You only add it once per bank, then pick it on the Dashboard every time you load a statement from that bank. Open one of your statements in Excel next to this guide while you fill it in.

1. Title

Any name that helps you recognise the format, for example SBI Savings. Every format needs a different title.

2. From Row

The row number of the header row, the row that holds the column names. Rows above it (bank name, address, account details) are ignored. In the example the header SRL NO, Tran Date, CHQNO ... is on row 4, so From Row is 4.

3. To Row or Till the end

The row number of the last transaction. Most statements have a different number of rows every month, so it is easier to tick Till the end: transactions are then read until the first empty row, and anything after it (totals, disclaimers) is left out.

4. Map Columns

Type each column name exactly as it is written in the header row. Capital letters matter, extra spaces at the start or end don't. Leave a field empty if your statement doesn't have that column.

5. Split transaction details (optional, recommended)

Banks usually pack several things into the details column. Splitting it gives you a separate transaction number and transaction source (who you paid or who paid you). The source is what tags and categories work on, so this is where the tool gets most useful.

Take UPI/P2M/1234567896/Random CAB from the example. Cutting it at every / gives these parts, counted from 1:

Part1234
TextUPIP2M1234567896Random CAB
  • Separator: the character between the parts, here /. Some banks use - or : instead.
  • Tran. No. Index: the part that holds the transaction number, here 3.
  • Tran. Src. Index: the part that holds the source, here 4.
Good to know
  • Dates are read day first, e.g. 22-04-2024, 22/04/24 or 22 Apr 2024. Rows without a readable date (wrapped text, totals) are skipped and the Dashboard tells you how many.
  • Amounts can contain commas or currency text such as 1,234.50 or Rs. 500.
  • If a column name doesn't match, the Dashboard shows which ones are missing and lists the names it found, so you can correct the format with the edit button.
